# Staff Payslip Management System

A desktop application developed in **C# (Windows Forms)** for managing employee payroll records and generating professional staff payslips.

> **Note:** This repository contains the compiled application and project documentation. The original Visual Studio source code is no longer available.

---

## Overview

The Staff Payslip Management System was developed to simplify payroll management by providing an easy-to-use desktop application for maintaining employee records, calculating salaries, and generating printable payslips.

The application provides a centralized platform for payroll administration, helping organizations reduce manual calculations, improve accuracy, and streamline salary processing.

---

## Features

- Employee Registration and Management
- Salary Calculation
- Payslip Generation
- Printable Payslips
- User Authentication
- Payroll Record Management
- Simple and User-Friendly Interface

## Getting Started

### Requirements

- Windows Operating System
- .NET Framework (if required by the application)

### Running the Application

1. Download or clone this repository.

```
git clone https://github.com/Dacell-maker/staff-payslip-management-system.git
```

2. Open the **Application** folder.

3. Run:

```
Staff Payslip Management System.exe
```
